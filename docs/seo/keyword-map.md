- رفوف طبالي, heavy/medium, system selection → /warehouse-racking.
- Supermarket, grocery, pharmacy and general shop shelving → /retail-shelving; /sectors is the index, not a competing landing page.
- Company/installation queries use the city hub where city-qualified; avoid stressing installation until client confirms actual scope.
- Exact brand phrase → /.
- English terms are secondary hypotheses only. Existing content is Arabic; do not build an English target until English lead-handling and original English copy are confirmed.

## Future pages: only after evidence and client confirmation

These are candidates, not a build queue. Require a separate intent, real capability, original copy, imagery/specifications and internal-link plan.

1. /pallet-racking — strongest specialist candidate. Target رفوف طبالي / pallet racking. Buyer: warehouse procurement. H2s: supplied system types, pallet/layout inputs, project process, installation boundaries, genuine case. Do not publish capacity without approved technical data.
2. /pharmacy-shelving — only if fixtures and installation are a distinct, proven service. Target رفوف صيدليات. H2s: fixture types actually supplied, product organization, layout inputs, project example. No regulatory claims without evidence.
3. /supermarket-shelving — only if it can add meaningful unique supermarket-specific project content beyond /retail-shelving. Do not imply refrigeration or turnkey fit-out unless confirmed.
4. /warehouse-racking-installation — only if installation is confirmed and distinct from supply; document steps, responsibilities and evidence without unsupported safety guarantees.

For each candidate: obtain client approval on service scope, photos and publication permission; use a unique title/description/H1, helpful original H2 content, links from the relevant specialist and city page, and a WhatsApp CTA that asks useful project questions. Avoid city-template/doorway pages.
