# موقع الشامخ للرفوف والديكورات

موقع عربي متجاوب مبني باستخدام Next.js. التواصل والتفاصيل التجارية تتم عبر واتساب، ولا تُنشر أسعار ثابتة.

## التشغيل

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`.

## قبل النشر

اضبط `NEXT_PUBLIC_SITE_URL` على النطاق الفعلي للموقع حتى تُنشأ الروابط الأساسية وخريطة الموقع والبيانات المنظمة بالنطاق الصحيح. راجع النصوص التجارية والصور مع صاحب المشروع، خاصة تصنيف الصور حسب القطاع. الشعار المرفق كان ضمن لوحة عرض وليس ملف شعار بخلفية شفافة؛ استبدل `public/reference/logo.jpg` بملف الشعار الأصلي عندما يتوفر.
